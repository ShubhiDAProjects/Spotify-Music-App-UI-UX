# 🎵 Spotify – Music Streaming App UI/UX Design

### Designed by Shubhi Shrivastava

A modern and visually engaging Music Streaming App UI/UX concept inspired by Spotify, designed in Figma.

This project focuses on creating a seamless music listening experience with intuitive navigation, attractive layouts, and user-friendly interfaces.

---

## 🎨 Project Overview

This project showcases a music streaming mobile application concept, covering the user journey from landing and login to exploring music playlists and viewing song details.

## 📱 Design Screens

The project includes 6 carefully designed screens:

1. 🚀 Landing Page
2. 🔐 Login Page
3. 👋 Logout Page
4. 🎶 Song Playlist Page
5. 🎧 Song Detail Page
6. 🏠 Home Page
